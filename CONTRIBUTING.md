# Contributing

Привет! Спасибо за интерес к проекту. Ниже — краткие правила, чтобы PR проходили гладко.

## Как начать
1. Установите зависимости: `pip install -e .[dev]`.
2. Перед работой изучите `README.ru.md` и `LEGAL.md`, чтобы понимать ограничения проекта.
3. Создайте ветку с осмысленным именем.

## Стиль и качество
- Код: Python 3.10+, типизация обязательна (`mypy`). Соблюдаем `black`/`isort`/`ruff`.
- YAML/Markdown: проверяем `yamllint`, не кладем секреты и реальные идентификаторы клиентов.
- Комментарии добавляем только там, где без них сложно понять намерение.

## Проверки перед PR
- Линт: `scripts/lint.sh`
- Безопасность: `scripts/security_scan.sh`
- Тесты: `pytest` (юнит+интеграционные тесты из `tests/`).
- При существенных изменениях алгоритмов — запустите `scripts/perf_check.sh` и приложите результаты.

## Набор изменений
- Одна функциональность — один PR.
- Обновляйте `CHANGELOG.md` и, при необходимости, `README.md`/`README.ru.md`.
- Не увеличивайте API без обратной совместимости без обсуждения.

## Обсуждения
- Предлагайте улучшения через issues или черновые PR.
- Вопросы по комплаенсу/санкциям не решаются в коде: обсуждайте отдельно с юридическими специалистами.

## Лицензия
Вклад принимается под лицензией Apache-2.0. Отправляя PR, вы подтверждаете согласие на распространение изменений под этой лицензией.
